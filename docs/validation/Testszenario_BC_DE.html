Testszenario BC

Basis-Import auf Gerät B gegen separates Hochlast-Szenario auf Gerät C.

Einsatz: Verwenden, wenn zwei vorbereitete Startzustände gegeneinander geprüft und anschließend gemerged werden sollen.

1) Beteiligte Geräte

GerätStartzustandUnterlagen
Gerät Bbasis_veranstaltung.json importieren, danach 0 KäufeRauchtest_DE.html, Ansage-Skript_B_DE.html, TC_Multidevice_Merge_Device_B_DE.html
Gerät Cteam_c_hochlast_start.json importieren, danach 300 KäufeRauchtest_DE.html, Ansage-Skript_C_DE.html, TC_Multidevice_Merge_Device_C_DE.html

2) Validierung

  • Vor-Merge-Werte für Gerät C und Nach-Merge-Werte für BC aus Validierungstabelle_AC_BC_DE.html verwenden.
  • Im Dokument das Szenario BC markieren.
  • Beobachtungsvorlage_DE.html verpflichtend verwenden, insbesondere Abschnitt B für Last-/Reaktionsbefunde.
  • R-01 auf Gerät C ist verpflichtender Bestandteil des Szenarios.

3) Ablauf

  1. Rauchtest auf Gerät B und Gerät C durchführen.
  2. Gerät B arbeitet K-08 bis K-14 ab.
  3. Gerät C führt R-01 sowie K-15 bis K-21 aus.
  4. Vor-Merge-Prüfung auf B und C durchführen.
  5. Beide Geräte exportieren und wechselseitig mit Merge importieren.
  6. Nach-Merge-Prüfung mit der BC-Sektion in Validierungstabelle_AC_BC_DE.html abschließen.
