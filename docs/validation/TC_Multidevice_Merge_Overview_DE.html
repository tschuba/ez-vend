1) Ziel und Testumfang

  • Parallele Erfassung von Kassiervorgängen auf mindestens 2 Geräten.
  • Prüfung der Ergebnisse vor Merge auf beiden Geräten.
  • Wechselseitiger Import der Exporte (A importiert B und B importiert A).
  • Prüfung der Ergebnisse nach Merge auf beiden Geräten.
Kontrollfälle: Es werden explizit beide Grenzfälle geprüft: Netto = 0,00 € und Netto < 0,00 € vor Begrenzung auf 0,00 €.
