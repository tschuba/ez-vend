Your data exists only in this browser — if it is lost, it cannot be recovered.

  • There is no cloud backup — clearing your browser data permanently deletes everything.
  • Export a backup file regularly to protect your event data.

This app stores all your data directly in your browser using a technology called IndexedDB. Unlike a cloud service, there is no copy stored on a server — your browser is the only place this data exists.

Browser storage can be deleted by clearing site data, uninstalling the browser, or if your device runs out of storage space. When this happens, the data is gone with no way to recover it.
